# Siddhi Jain & Associates — Website

Static, Vercel/GitHub-ready website.

## Files
- `index.html` — homepage
- `about.html` — firm profile
- `services.html` — services
- `tools.html` — calculators/tools
- `insights.html` — knowledge centre
- `contact.html` — contact/offices
- `assets/style.css` — complete design system
- `assets/script.js` — calculator/menu interactions
- `robots.txt`, `sitemap.xml` — SEO basics

## Publish on Vercel
Import the GitHub repository into Vercel. Framework preset: **Other**. No build command is required; publish the project root.

## Current tool set
The Tools page contains: Valuation, ROC & Listed-Entity Compliance Calendar, MCA Late Fee Estimator, Shareholding Dilution, DCF Valuation, FDI/FEMA Reporting Guide and IPO Readiness. The incorporation-fee calculator has been removed. The professional Word format library has been restored and expanded with 28 working formats: 10 Board resolutions, 10 Board minutes formats and 8 listed-company Board outcome formats.
